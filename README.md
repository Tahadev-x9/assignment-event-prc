Event Practice Website :

A modern and responsive Event Management Landing Page built using HTML, CSS, and JavaScript.
This project showcases a clean UI for promoting events, highlighting services, schedules, speakers, and encouraging
users to explore or register for upcoming events.

🌐 Live Demo

🔗 Live Website: https://eventprac.netlify.app/

📖 Overview

This project is designed as a front-end event website with a modern layout and responsive design.
It focuses on delivering an engaging user experience while demonstrating strong front-end development skills.

The website includes multiple sections such as:
Hero Banner
About Section
Event Information
Services
Featured Events
Speakers
Schedule
Contact Section
Responsive Footer
